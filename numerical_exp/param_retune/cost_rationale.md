# 成本参数重标定说明（福田）

## 问题诊断

旧基准 \(\rho=2,c^f=41,c^m=45\), hub \(50\) 下：

- fixed-only / centrally / locally 利润都在约 \(68000\) 附近
- mix 相对 fixed-only 只高约 \(35\)–\(42\)，相对增幅约 \(0.05\%\)–\(0.06\%\)
- 三种模式运营利润几乎相同；差距几乎全来自投资项，而 \(c^f\approx c^m\) 时投资差只有几十

要把相对增幅拉到 \(5\%\)–\(10\%\)，必须让固定桩（含土地）明显贵于移动桩，使 mix 用更少固定桩 + 有限移动车队省下可观投资。

## 约束：本地模式不能退化成纯移动桩

本地模式车队上界 \(m\_bar=35\times 30=1050\)，几乎不绑车队规模。若 \(c^m\) 相对 \(c^f\) 过低，DRO 会把固定桩全部换成移动桩（例如 \(c^f=117,c^m=49\) 出现 \(n=0,m\approx 327\)；\(c^f=180,c^m=125\) 同样 \(n=0\)）。

经验上，DRO 下要保持“固定基荷 + 移动补充”，宜保持 \(c^m/c^f \approx 0.75\)–\(0.80\)（对照能保住结构的 \(75/58\approx 0.77\)）。

## 推荐基准（已写入 `futian/business.json`）

| 参数 | 旧值 | 新值 |
| --- | ---: | ---: |
| \(c^f\) | 41 | **150** |
| \(c^m\) | 45 | **115** |
| hub | 50（文件曾为 55） | **160** |
| \(\rho,g,\gamma\) | 2 / 0.25 / 0.001 | 不变 |

### 依据（日摊销，人民币）

1. **\(c^f=150\)**：设备+安装+配电分摊约 \(40\)–\(50\)/日（沿用旧设备口径）；福田永久车位/场地约 \(100\)–\(110\)/日（约 \(3000\)–\(3300\) 元/月）。公开报道里充电车位月租常见两三千到五千，极端接近万元，故 \(150\) 表示“含土地的贵固定桩”，不是纯设备价。
2. **\(c^m=115\)**：中等规格移动储能充电单元约 \(25\) 万级，按 \(6\) 年摊销约 \(114\)/日；**不含**永久车位。与 \(c^f\) 之比约 \(0.77\)，接近可保住固定基荷的比例。
3. **hub=\(160\)**：非核心区车队场站/夜间补能用地日成本，略高于单根 CBD 桩的土地份，但远低于多根固定桩土地之和。

### 单位容量关系

- \(c^f/v^f=150/190\approx 0.789\)
- \(c^m/v^m+g=115/160+0.25\approx 0.969\)
- 常开基荷仍偏向固定桩；移动桩靠跨区、跨日期类型的灵活调配创造价值。

### 期望增幅（均值需求快筛，供方向；DRO 会再收一点）

在“固定仍作基荷”的结构下：

- charge centrally：约 **\(4.5\%\)–\(5.5\%\)**（常开 \(2\) 个 hub、车队触及每 hub 上界 \(30\) 时靠近上沿）
- charge locally：约 **\(1.5\%\)–\(2.5\%\)**
- 配置大致：centrally \(m\approx 60,n\approx 218\)；locally \(m\sim 30\)–\(50,n\sim 230\)–\(250\)；fixed-only \(n\sim 275\)

若强行把 \(c^m\) 再压低以冲 \(10\%\)，本地 DRO 很容易变成纯移动桩，论文叙事会坏掉。

## 若必须两边都稳定 \(\ge 5\%\)

只改三个成本不够稳妥。更干净的做法是给本地模式加合理车队上界（例如全市 \(m\le 60\)），再采用更进取的土地溢价，例如 \(c^f=180,c^m=115\), hub \(160\)。车队上限会阻止“用几百台移动桩清空固定桩”。
